# Public repository sanitization checklist

Before publishing this repository or attaching it to LinkedIn:

- [ ] Remove Pixel IDs, dataset IDs, ad-account IDs, store admin URLs, and API tokens.
- [ ] Remove customer names, phone numbers, addresses, order IDs, and payment details.
- [ ] Crop screenshots to evidence panels only; exclude browser address bars and account identifiers.
- [ ] Keep campaign totals labelled as screenshot evidence and preserve their reporting scope.
- [ ] Do not include supplier credentials, Shopify admin exports, or private client files.
- [ ] Re-run the analysis and tests after any data edit.
- [ ] Review the repository once as a public visitor before sharing the link.
